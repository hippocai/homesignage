# HomeSignage 系统回归测试

适用于准备发布、升级已有家庭实例，以及交接后排查“后台能配置、屏幕没反应”的问题。先在隔离环境复现，再对运行中的服务做只读冒烟检查。下表中的短名称对应 `tests/<名称>.test.js`。浏览器脚本在内存库和随机回环端口运行，通过真实 HTTP 和 Socket.IO 连接后台与显示屏。

## 准备与复跑

1. 使用 Node.js 22 或 24，在仓库根目录运行 `npm ci`，然后运行 `npm --prefix admin ci` 和 `npm --prefix admin run build`。后台测试需要构建后的 `admin-dist/`。
2. 执行 `npm test`。如需逐例结果，可执行 `npm test -- --json --outputFile=jest-results.json`；生成物仅供本地检查。
3. 设置 `CHROME_PATH` 为本机 Chrome 可执行文件，运行 `npm run test:browser`。也可用 `npx playwright-core install chromium` 安装 Playwright 对应的浏览器。这一轮使用模拟天气、股票和模型响应，便于复现边界情况。
4. 有 GLM 凭据时，执行 `npm run test:agent:live` 和 `npm run test:browser -- --live`。前者用虚构的家庭资料、航班和道路公告运行真实模型，后者使用真实新闻和模型走完整播报流程。运行 `npm run test:browser -- --live --zaobao` 可改用联合早报。此组会消耗供应商配额。
5. Docker 环境从干净仓库复制 `.env.example` 为 `.env`，设置 JWT 密钥，运行 `docker compose up --build -d`。访问 `/api/v1/health`、`/admin/` 和 `/api/docs.json`，重启容器后检查设备与场景仍在。请在独立测试目录和测试端口执行。
