# HomeSignage 接口指南

启动服务后访问 [Swagger UI](http://localhost:3000/api/docs/) 或下载 [OpenAPI JSON](http://localhost:3000/api/docs.json)。JSON 包含每个操作的方法、路径、参数、身份和响应。常规 API 前缀是 `/api/v1`。网页代理单独位于 `GET /url-content`。

| 调用方 | 凭据 | 典型操作 |
| --- | --- | --- |
| 管理后台 | 登录后发送 `Authorization: Bearer <JWT>` | 管理设备、场景、媒体、订阅、模型设置和家庭审计 |
| 家庭自动化系统 | 后台生成的 `X-API-Key` | 修改指定画面的文字、切换画面、创建或解除提醒；支持范围逐项见 Swagger |
| 显示屏 | `X-Device-Key` 与路径中的设备 ID 配对 | 获取设备配置、资讯和伙伴任务，领取任务并上报结果 |
| 聊天链接访客 | 同源访问 `/pig-chat`，由服务签发 HttpOnly Cookie | 访客发送消息、查询或更改本会话创建的系统记录 |

## 集成流程

1. **后台与设备。** 管理员 `POST /auth/login` 登录，`POST /devices` 注册屏幕；`POST /scenes` 新建画面，`POST /scenes/{id}/components` 添加组件。再用 `PUT /devices/{id}/scenes` 提交 `{"scenes":[{"sceneId":"…","duration":60}]}`。屏幕携带设备密钥读取 `GET /devices/{id}/config`。
2. **股票、天气与媒体。** 使用 `GET /stocks?symbol=300750&market=cn` 读取行情和分时点；组件保存比例尺。实时天气使用 `GET /weather?city=Beijing`；天气地点搜索和服务商列表需后台 JWT。播放带空格、百分号等字符的视频时，对文件名进行一次 URL 编码，`GET /file-repo/{filename}/stream` 支持 `Range: bytes=-1024`。整段返回 200，部分返回 206，无法满足的区间返回 416。
3. **订阅与显示。** `GET /news/presets` 列出预设；`POST /news/presets/{key}/subscribe` 返回 `{data:{id,added}}`，重复调用可安全重试。自定义来源用 `POST /news/sources`；`POST /news/sources/{id}/test` 仅返回样例，`…/scan` 才处理事件。屏幕用设备密钥获取 `GET /devices/{id}/news`。
4. **伙伴气泡。** 组件 `config.reminders` 保存类型、声音和音量；全局 `/companion/settings` 保存12段 `greetingSchedule` 和免打扰设置。全部猪猪组件共享同一条模型气泡。屏幕读取 `GET /devices/{id}/narration?componentId=…`；向 `/devices/{id}/narration/{event}/claim` POST `componentId` 领取朗读权，向同路径 `result` 提交 `componentId/result`。模型生成普通问候与提醒，旧 `/briefing` 和 `/deliveries` 只保留兼容。
5. **聊天和审计。** 管理员从 `GET /companion/agent/share` 获取分享链接。可设置环境变量 `PIG_CHAT_PUBLIC_ORIGIN` 指定浏览器能访问的站点地址（含映射端口），默认使用请求地址。任何能打开链接的人都能聊天。访客先 `POST /pig-chat/session`，随后保留 Cookie 向 `POST /pig-chat/messages` 提交 `message` 与 `requestId`（可附昵称）。网络重试复用同一编号。助手操作定时提醒和信息列表时，改期保留原记录编号。管理员通过 `GET /companion/agent/audit` 查看原请求、结果及操作前后数据。
6. **健康与故障。** `GET /health` 用于启动检查，无需登录；`GET /system/status` 需要管理员身份。非法 JSON 返回 400，JSON 请求体过大返回 413。订阅/模型供应商错误与额度状态按具体操作查看 429、502 或 503。

网页代理允许公开的 HTTP(S) 页面，按最终页面 URL 解析相对资源，使用隔离沙箱。局域网网页可在 iframe 组件中关闭“服务器代理”，由显示屏直接访问。完整验收数据和复跑步骤见[系统回归测试](系统回归测试.md)。

管理员可通过 `GET /news/settings` 查看共享模型、密钥配置状态和今日用量，通过 `PUT /news/settings` 设置每日调用次数 `dailyCalls` 和令牌数 `dailyTokens`。两项独立，传 `-1` 表示不限额，`0` 表示零额度。通过 `PUT /model/credentials/{provider}` 提交 `{"apiKey":"新密钥"}` 设置或替换 GLM、DeepSeek 或 Brave 的凭据（路径参数为 `glm`、`deepseek` 或 `brave`），响应仅给出配置状态。

## 提前天气提醒与诊断

管理员 `GET /companion/agent/weather` 返回 `{data:{status,weather}}`。`weather.future`中每个城市包含`daily`（今天及未来7天）、`hourly`（48小时）、`alerts`（官方预警），每类独立返回`status`、`fetchedAt`、`items`和`attributions`。`fresh`表示本次缓存有效，`stale`表示旧数据，`unavailable`表示无法获得；只有`fresh`且预警列表为空才能解释为查询成功、暂无有效预警。聊天接口也使用这些字段作为模型上下文，城市从组件或家庭资料、近期有效计划中取得。

天气、新闻、家庭资料和系统事项现在统一进入气泡模型，不再由旧 weatherAgent 的温差、风险候选或提前窗口决定播报。模型生成时的请求与返回完整写入聊天审计，静默和到期约束仍由程序执行。天气来源与缓存规范继续沿用。

## 猪猪独立记忆、分钟间隔与审计筛选

`GET /companion/agent/narration-prompt` 返回 `prompt/defaultPrompt/isDefault/revision`。`PUT`同路径提交`{prompt,revision}`保存完整自定义文本，或`{reset:true,revision}`恢复默认。文本限1–20000字符，不允许空白；版本冲突返回409。保存后通知屏幕并使旧缓存失效，生成中的旧版本不会发布，不需重启。`GET /companion/agent/memory`新增`text`，返回与Markdown镜像相同格式的有效记忆文本，读取时先清理到期条目；两类接口均需要管理员JWT。

`GET/PUT /companion/settings` 的 `greetingSchedule` 必须是12个0–120整数，分别对应00–02至22–24时；0暂停生成。`quietEnabled/quietFrom/quietTo`配置全局免打扰，时间格式HH:mm，支持跨午夜，同起止表示不静默。时段使用只读`zone`家庭时区。旧`greetingMinutes`写入1–120时填充12段，读取返回当前段值。`GET /companion/agent/memory` 查看独立记忆和自动到期审计；通过原聊天接口增改删。记忆写入和聊天回执原子提交，临时记忆必须有结束时间，访客只能管理自己的条目。

`GET /companion/agent/audit` 支持 `type=all|chat|narration|system_prompt|model_context|model_response`、`scope`精确会话筛选和`before`分页；响应`users`提供用户选择列表。自动气泡的scope为`system:narration`。字段类型筛选只返回相应模型对话字段和元数据，不混入其他正文。

`GET /companion/agent/narration-prompt` 返回实际system prompt；`GET /companion/agent/narrations` 返回最近决策及展示回执。全部需管理员JWT。完整结构与专项用例见[猪猪模型气泡与独立记忆](猪猪模型气泡与独立记忆.md)。

共享气泡接口返回同一`id/speech`与请求组件自己的`componentId/preferences`。暂停时返回`paused:true,nextReviewAt,preferences`，无模型话语和领取ID；不能领取暂停或已过期决策。生成锁与缓存全家共享，审计只记录真实调用一次；`claim/result`按设备记录，同屏切换组件不重复朗读。新生成通过`briefing-updated`通知全部屏幕，30秒轮询兜底。
