# 猪猪模型气泡与独立记忆

## 使用方法

在「猪猪伙伴」底部的「气泡生成设置」配置生成间隔，范围为1–1440整数分钟，默认5分钟。屏幕在线并显示猪猪时，每30秒检查一次，按设置间隔重新生成；资料、记忆、天气、新闻或系统事项变化，以及旧话语到期时，会提前重新判断。后台轮询不等于每次调用模型，同一上下文的有效决策会复用。

每句话，包括普通问候，由共享模型设置中的GLM/DeepSeek生成。上下文包含当地日期、时区、农历和内置假期表、完整家庭资料、有效计划、独立记忆、天气观测、今天加未来7天日预报、48小时预报、官方预警、最多60条当前有效资讯、系统信息与定时提示、近期展示记录。缺少或过期的数据会标明状态。模型选择话题、重要程度、动作、有效期及是否再次提醒；旧固定问候和温差阈值不参与实际气泡播报。

系统默认提示词：[pig-screen-system.md](../src/prompts/pig-screen-system.md)。在「猪猪伙伴 → 气泡 System prompt」可查看、编辑、保存当前完整文本，也可直接恢复默认版本。自定义内容保存到数据库，重启和升级不会覆盖；保存/恢复后通知屏幕并使旧气泡缓存失效，新生成无需等原间隔，也无需重启。进行中的旧版本结果会被拒绝。多页面同时修改时，版本冲突返回409，页面保留草稿，避免互相覆盖。请保留JSON输出格式要求。聊天审计记录实际使用的自定义提示词。

家庭功能开关、免打扰、设备绑定、到期校验、请求去重和音频解锁仍由程序执行。免打扰期间只生成陪伴，不朗读。模型不可用或额度不足时显示明确服务状态，不用固定问候冒充模型输出。

## 独立记忆

示例：“明天早上提醒我拿红包，不要在系统添加提醒，只记在你自己的记忆里，明天中午忘记。”

- 猪猪新增独立记忆，回复说明有效期，不写`timed_reminders`或`info_items`，也不把它塞进家庭计划。
- “明早”没有明确时间时，提示词允许使用次日06:00–12:00，并结合已有作息；模型生成时优先考虑有效期内尚未播报的明确托付。
- “把红包事项推迟半小时，到期时间不变”：保留原ID，开始时间精确增加30分钟，保留结束时间。
- “查看你自己记住的事项”“取消红包记忆”：通过聊天查看和取消；同一访客只能管理自己写入的记忆。
- 临时记忆必须有到期时间；明确要求长期记住的事实可以无到期时间。用户提供的家庭基础资料仍由「家庭记忆」单独维护。

有效记忆保存在数据库`pig_agent_memory`，同时生成`data/pig-agent-memory.md`（权限600）的可读镜像。文件不是手工编辑入口，请通过聊天修改。启动时重建，后台每30秒和每次读取时清除到期条目；聊天、操作和自动到期的审计保留，不再参与当前有效记忆。可以用`PIG_MEMORY_PATH`改变镜像路径，需随数据卷持久化。

数据库触发器让记忆变化、聊天回执、版本更新和操作审计原子提交。重复`requestId`不会重复新增；修改取消必须使用本人原ID及版本；模型调用期间发生取消或到期，旧气泡不可发布或领取。文件投影与数据库分离，进程重启可从数据库恢复，避免文件损坏丢记忆。

这是在线助手的提醒能力，依赖屏幕在线、可用模型和允许的功能。需要精确闹钟或强制插播时，明确说“创建系统定时提示”。

## 聊天审计

「猪猪伙伴 → 聊天审计」支持：全部类型、用户对话、自动气泡完整对话、仅System prompt、仅模型上下文、仅模型返回；还可按用户会话筛选。同名访客用不同会话编号区分，用户昵称不是身份凭证。

每次真正生成气泡前记录实际system prompt、完整上下文、模型名称；模型返回后记录原始响应、结果和失败原因。JSON无效、预算用完、上下文变更也保留审计。缓存复用不会伪造一次新的模型调用。仅管理员可以读取这些包含家庭资料的记录，访客聊天接口不暴露系统审计。

「猪猪自己的记忆」默认以完整文本显示有效记忆，可选中复制，也可切换为列表，包含内容、生效时间、到期时间与编号。文本采用与Markdown镜像相同的格式，读取前清除到期条目；只读查看不修改记忆。下方保留最近50条记忆操作。「气泡判断记录」显示最近30条话语、模型理由、有效期和实际展示/朗读结果。

## 接口

前缀`/api/v1`。管理员接口使用JWT，屏幕接口使用`X-Device-Key`。

| 接口 | 用途 |
| --- | --- |
| GET/PUT `/companion/settings` | `greetingMinutes`整数分钟；旧`familyAI`字段只保留兼容 |
| GET `/companion/agent/memory` | 有效记忆、镜像位置、最近50条记忆审计 |
| POST `/companion/agent/messages`、`/pig-chat/messages` | 聊天管理独立记忆；沿用`message`和`requestId` |
| GET `/companion/agent/narration-prompt` | 返回`prompt/defaultPrompt/isDefault/revision` |
| PUT `/companion/agent/narration-prompt` | 保存传`{prompt,revision}`；恢复默认传`{reset:true,revision}`；文本1–20000字符，空白拒绝，版本冲突409 |
| GET `/companion/agent/narrations` | 最近30条决策与展示回执 |
| GET `/companion/agent/audit?type=system_prompt&scope=system:narration` | 审计筛选；`before`分页；响应`users`用于会话选择 |
| GET `/devices/{id}/narration?componentId=…` | 模型气泡，包含`id/speech/action/validUntil/nextReviewAt/preferences` |
| POST `/devices/{id}/narration/{event}/claim` | 传`componentId`，校验上下文；`accepted`表示本次是否取得朗读权 |
| POST `/devices/{id}/narration/{event}/result` | 传`componentId/result`；结果为`subtitle/spoken/interrupted` |

旧`briefing`和`deliveries`接口仅用于兼容；新展示端不再使用旧天气风险候选与资讯影响阈值选择播报。天气数据获取、来源缓存和新闻订阅保持原流程。

线上验收还修复了模型使用`clock`、`profile.memory`作为上下文引用时被误拒的问题，仅放行已实际提供的字段。部署至192.168.10.204后，实际模型生成、完整审计与prompt筛选通过；已核对原有数据、订阅配置和环境文件保留。备份与汇总证据见[验收记录](test-results/pig-memory-2026-11-09.json)。
